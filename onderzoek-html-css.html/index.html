Waarom noem je de eerste HTML-pagina meestal index.html?

Omdat index.html traditioneel de standaard startpagina van een website is.

Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

Webontwikkelaars gebruiken tegenwoordig de HTML Living Standard van de WHATWG.

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

Omdat CSS tegenwoordig is opgebouwd uit verschillende modules die onafhankelijk van elkaar worden ontwikkeld en bijgewerkt.

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?
